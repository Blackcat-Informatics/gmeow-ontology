# software

> **Slice:** `https://blackcatinformatics.ca/gmeow/slices/software` · **tier: extension**

The software slice: a five-facet de-conflation of the project domain. Project ≠ Product ≠ Codebase ≠ Repository ≠ History. Each facet is separately identified, separately classed, and never bridged by subclassing or equivalence. DOAP's original sin — collapsing endeavour, product, repo, and history into one class — is corrected here; DOAP is aligned by reference as a lossy downcast, never imported (Principle 5). REUSE. - Events / Participation / Activity: events.ttl, provenance.ttl - Contribution / ContributionRole: creative-works.ttl - VersionSet / VersionMembership: versions.ttl - …

*This is a STUB guide (#325 Tier-2): the slice is modelled, aligned, and
reasoned, but its narrative documentation has not been written yet. The
module-status matrix tracks the gap; term-level documentation (labels,
definitions) lives in `module.ttl` and renders via `gmeow describe`.*
