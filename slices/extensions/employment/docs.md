# employment

> **Slice:** `https://blackcatinformatics.ca/gmeow/slices/employment` · **tier: extension**

Employment relationships, compensation, and career events (the ResumeRDF / Europass / schema.org / ESCO / CTDL superset layer). STANDPOINT DOCTRINE (#51). Contested facts in the employment slice — disputed tenure, rival role claims, contested termination — are standpoint-indexed claims that COEXIST, none privileged (Principle 9). A contested employment is two gmeow:accordingTo-annotated gmeow:memberOf base triples, or two reified gmeow:Employment relators each carrying gmeow:accordingTo. A withdrawn employment record is modelled with gmeow:displayable false, never deletion (Principle 10) …

*This is a STUB guide (#325 Tier-2): the slice is modelled, aligned, and
reasoned, but its narrative documentation has not been written yet. The
module-status matrix tracks the gap; term-level documentation (labels,
definitions) lives in `module.ttl` and renders via `gmeow describe`.*
