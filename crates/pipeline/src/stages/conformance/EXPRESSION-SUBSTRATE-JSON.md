# Expression-substrate observation JSON

The five selected expression scenes use native JSON at their inner action caches, final observation publisher and authenticated corpus reader. Native record codecs preserve compact UTF-8 without a newline in declaration order. Maps sort keys; declared-key vectors and BuildIdentity features preserve their original order and repeated entries. Source, projection and producer digest strings are transported unchanged.

Profile admits the exact `Reference`, `Twins`, `MultiGraph` and `Control` strings or their singleton-null-object unit forms, emitting strings. Records admit objects, ignore unknown fields, refuse known duplicates and require correctly typed mandatory fields. Positional record arrays are not admitted. `reasoned`, `multi_graph_findings` and `expression_findings` admit missing or null as absence and emit explicit null. Present empty finding vectors remain present empty vectors. The operator-less-root edge count requires an unsigned integer token and checked usize bounds, refusing negative zero, negatives, fractions, exponents and overflow. Typed maps validate each duplicate value before last-wins replacement.

BuildIdentity's native codec lives with the original cache owner and contains exactly fingerprint, toolchain, target, profile and ordered features. Its genuine Serde embeddings remain separate. The codec never obtains host identity. Source/TBox selection, all scene computations, domain and payload identities, cache operation names and selector authentication are unchanged. Authored transport tests use plain values and literals; no test invokes the inline expression controls, canonical source parsing or reasoning. Existing corpus contracts retain their independent assertions and require separately supplied authenticated producer output.

The inference-validation channel uses the same native cache core for its two selected controls and shares one concrete DTO owner, `gmeow_validate::inference_observation`, between publication and authenticated reading. Its profile, source digests, control identities and shape validation remain with the existing callers. Ordered severity/message rows preserve nullable messages: missing or null decodes as absence and emits explicit null, while present empty text remains a string. Severity strings are transported verbatim. The existing `violations` view selects the exact SHACL Violation IRI in row order and retains an empty display for an absent message. The shared DTO owner has no repository, selector or producer dependency. The integration reader has one selector-bound entrypoint with a required decoder chosen explicitly at each actual caller. Inference chooses native JSON; its grounding and medium-axis siblings retain Serde. A decode failure never falls back or produces an artifact.

The retained grounding reader uses its existing UnitInterval owner and fixed four-component RDF-literal tuple for confidence. Its foundational presentation reads the original literal lexical form, preserving decimal spelling and datatype. Grounding transport remains Serde-owned; this type correction does not introduce another numeric parser or migrate the enclosing catalog.
