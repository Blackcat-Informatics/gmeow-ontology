# Vendored fragment — UD_English-EWT (ring-fenced)

`en_ewt-ud-dev-fragment.conllu` is a small, **ring-fenced** vendored fragment of the
**UD_English-EWT** treebank, reproduced here **verbatim** (upstream bytes exactly: LF line
endings, tab-separated columns, one terminating blank line per sentence) purely as a
correctness fixture for the `lang:` CoNLL-U byte round-trip (Gate 2).

- **Treebank:** UD_English-EWT (Universal Dependencies — English Web Treebank)
- **Authors / credit:** the Universal Dependencies project and the EWT treebank authors
- **License:** CC BY-SA 4.0 (`CC-BY-SA-4.0`)
- **Source:** <https://raw.githubusercontent.com/UniversalDependencies/UD_English-EWT/master/en_ewt-ud-dev.conllu>
- **Upstream ref:** `master` (fetched 2026-07-11)

This fragment is NOT part of the CC BY 4.0 GMEOW vocabulary and is never merged into it: it is
a clearly-separated, fully-attributed vendored corpus under its own CC BY-SA 4.0 terms. The
exact sentences vendored (by `sent_id`) are declared in `corpus.json`, alongside the SPDX
license, source URL, upstream ref, attribution, and the ring-fence flag that make it
`IMPORT_OK` under the native license policy (`gmeow_license::policy_for_vendored_corpus`).

The upstream `.conllu` content is preserved exactly; no GMEOW SPDX header is injected into it
(the fragment is not our copyright).
