# sources

> **Slice:** `https://blackcatinformatics.ca/gmeow/slices/sources` · **tier: core**

Sources, citations, and the evidence layer — a cross-cutting facility (reused by genealogy and every other slice) for evidence-based, source-cited claims. Refactored in #211: the anti-rigid Source Kind is retired; source-hood is mediated by CitationAct or borne as SourceRole. The Citation locator is retired in favor of Selector (in the citations module). Carrier metadata now applies to Manifestation/Item.

*This is a STUB guide (#325 Tier-2): the slice is modelled, aligned, and
reasoned, but its narrative documentation has not been written yet. The
module-status matrix tracks the gap; term-level documentation (labels,
definitions) lives in `module.ttl` and renders via `gmeow describe`.*
