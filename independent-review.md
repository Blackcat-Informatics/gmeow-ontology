## Initial blocking finding — repaired on narrow delta review

`crates/cli-core/src/ndjson.rs` encodes StageEnd with `elapsed_ms.to_json()`. The selected pinned native owner does not implement `ToJson for u128`: `lex/src/json/record.rs:1223–1235` enumerates integer codecs without u128. The earlier `native_integer_value!` list containing u128 implements the different allocation-admission `IntoJsonNative` trait, not ToJson. Therefore this StageEnd writer cannot compile. Native `Value::from(u128)` is supported (`lex/src/json/value.rs:1075`); use that actual owner directly for the dereferenced elapsed value, without narrowing or a new codec. Keep the independent literal `u128::MAX` expectation unchanged. This finding blocks qualification until repaired.

Narrow delta review confirms StageEnd now inserts `Value::from(*elapsed_ms)` directly through the existing full-width native constructor. The independent `u128::MAX` literal expectation remains unchanged. The wire document now has the standard copyright and CC-BY-4.0 SPDX header. Both findings are resolved in source; no other path was re-reviewed for this delta.
