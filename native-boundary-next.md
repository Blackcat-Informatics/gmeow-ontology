# Actual native seams for the next implementation

Inspected at merged native50172ad55; these are source observations, not completed capabilities.

The source-bound positive application journal already exists in entail/src/owl_dl/support.rs. Journal stores each application once in an arena with a predecessor link; a branch copies only Cursor. Applications retain clause, actual frame, selected branch and licensed heads. extract currently materializes only SchemaClashEvidence and requires a SchemaBoundEvidence. The checker in owl_dl/proof.rs replays that prefix from consumer assertions/refutation assumptions for prepared cardinality clashes. This is a reusable owner for extending actual premise reachability, not a reason to build a second GMEOW proof engine or guess support from a final closure.

Legacy ClashStep currently carries clause/node/frame/witness plus optional schema evidence. Its public docs explicitly state that ordinary witness reachability is not established. NodeRef::Individual(u32) is an interner ordinal; DlProofContext publicly exposes only input/contract/clause_count. Its knowledge base/clauses and asserts helper are private. No public checked ordinal-to-source resolver was found. A new checked support/source-resolution boundary must preserve trusted versus unattested counts, exhaustive branch checking and anonymous/generated witness identity; it cannot turn the legacy frame check into rooted source support by renaming it.

Borrowed source construction is closer than the public API suggests: Kb::from_dataset, from_dataset_until and from_dataset_with_preparation already accept generic DatasetView; parser and query data-index/class-signature helpers are generic. Public Reasoner constructors, ontology identity, DlProofContext::of_ontology and ServiceProof::binds/verify still require RdfDataset. Generalizing the actual constructor/identity/checker path could remove a materialization boundary, but fallible source admission must cover every drain, including post-parser indexing, and preserve original refusal/evidence. It is not an append/delta API: no public monotone class-state update was found. Shared graph selection must preserve the full statement layer and exact world identity.

GMEOW casesplit/execution.rs still uses its own scan, frozen-schema frontier, positive row-prefix observations and cached last result. Any replacement must preserve those actual production semantics, disconnected rooted witnesses, late-equality/closure ordering and completed-read gates. A global False consistency answer alone cannot be converted to a local conflict head. The existing recorded-class-consistency example selects an authenticated whole world and uses DlReasoner::with_proofs; it has no caller stop selection, so do not invent a non-firing signal merely to make the new API appear wired.
