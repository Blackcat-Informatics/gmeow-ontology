# Retained native term JSON

`term_serde::to_json` and `term_serde::from_json` use the existing value-only representation and its TermValue conversions. The logic facade reexports these entrypoints. The native codec does not pass through Serde, reinterpret RDF strings, validate RDF position legality, normalize lexical values or use dataset-local term IDs. Existing Serde term embeddings and optional/vector helpers keep their separate callers.

The four exact singleton variant objects are `Iri` with a string, `Blank` with ordered `label` and unsigned u32 `scope`, `Literal` with ordered `lexical_form`, `datatype`, `language` and `direction`, and recursive `Triple` with ordered `s`, `p` and `o` terms. Blank scope uses strict unsigned integer tokens; negative zero, negatives, fractions, exponents and overflow refuse. Literal language and direction admit missing or null as absence and emit explicit null. Directions admit `Ltr` or `Rtl` strings and their exact singleton-null-object forms, emitting strings. Struct payloads admit objects, ignore unknown fields and refuse known duplicates; positional struct arrays are not admitted. Recursive term and field errors retain their complete member pointers.

Glossary observations preserve exact three-element subject/predicate/object arrays, ordered duplicate rows and sorted source maps. Each source result is an exact singleton `Ok`/`Err` object carrying its vector or complete recorded diagnostic. Native typed maps admit every duplicate value before last-wins replacement. The standalone alpha-drift channel similarly retains its original path, source digest, ordered findings and recorded failure. Glossary source outcomes, the auxiliary outcome and the reviewed-coverage outcome all use the fixed-RecordedDiag writer beside their shared recorded-result reader in gmeow_errors::json, retaining the same singleton bytes. Its broader grounding Scene, ModalProduct, DimensionFindings, ReasoningResult and domain/payload digest ownership are unchanged.

Both selected channels use the native file-cache adapter. Native and Serde file adapters share one source-byte/path/digest preparer and the existing coordinated byte-action core. File-read error priority, relative-path spelling, action operation/input/build identities and selector authentication remain unchanged. A malformed completed native hit is terminal and never retries its producer. Outputs remain compact UTF-8 without a trailing newline. Authored codec and temporary-file controls need no corpus; actual corpus consumers retain their independent source and semantic assertions.
