## Findings

### REQUIRED (text only; "the code is correct")

- **REQ-A** `slices/core/pipeline/module.ttl` line 262, the definition of `gmeow:laneAllArtifacts`, ends
  "Committed artifacts survive the release of the producer's carrier, so this read alone does not keep the
  carrier resident." False at the head: a view in flight defers the swap, so the read keeps the whole carrier
  resident until the consumer ends.
- **REQ-B** `crates/pipeline/src/scheduler.rs`, the doc of `CarrierRetention::DropAfterLastConsumer` (about
  lines 84 to 90): says the carrier is released "when its exact remaining carrier-reader count reaches zero"
  and "freed as soon as no stage can still read them". The release also waits for views in flight.
- **REQ-C** `crates/pipeline/src/run.rs` lines 477 to 478 ("release each stage's carrier once its last
  declared carrier consumer has run (or after production when every later edge is artifact-only)") and the
  doc of `last_consumer_levels` in `scheduler.rs` (about line 1147: "Production release now uses exact
  remaining-reader counters at completion time"): both inexact for the same reason.
