# Saved review representation

Saved GitHub discussion captures omit the nonfinding bot HTML provenance marker rejected by the normal Git attribution guard. All review findings, code suggestions, author fields, IDs, URLs and pagination fields remain available; no substantive finding is removed or encoded. Original public bodies remain retrievable through their recorded GitHub URLs. This representation applies to the saved Markdown and JSON copies, not to source or the public discussion. It was checked against the guard's attribution patterns without changing the guard or reading machine configuration.

New PR feedback must be refreshed and assessed before merge. No unavailable review is described as approval. The selected Stage directory is archived separately by ghprsq and is not added to source commits.
