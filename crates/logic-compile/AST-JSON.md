# Canonical compiler AST JSON

The native JSON codecs carry the existing compiler Term, Formula and Diagnostic types. Genuine Serde and binary embeddings remain intact. Encoding preserves the stored AST: operand order, nested connective structure, application arguments, binder names and binder-vector order are not rewritten, sorted, alpha-normalized or routed into a Horn representation.

Term has the five exact singleton tags `Var`, `Iri`, `Literal`, `SequenceMarker` and `App`. Formula has the eight exact singleton tags `Atom`, `Not`, `And`, `Or`, `Implies`, `Iff`, `Forall` and `Exists`. Struct payloads preserve declaration order. `Implies` and `Iff` carry exactly two ordered array elements. Variadic connective vectors and binder vectors keep their existing admission, including empty/single connectives and repeated binder names; transport adds no arity or binder policy to those enum variants.

An IR Literal uses the existing fixed four-element array `[lexical, datatype, language, direction]`. The first two fields are strings; the last two are explicit nullable string cells. Direction uses lowercase `ltr` or `rtl`, distinct from the retained TermValue representation. Both codecs reuse the single-literal owner for RDF component coherence, implied datatype and lowercase language normalization. Lexical values are not numerically parsed or normalized. The vector literal owner, with its separate sorting and deduplication policy, is not used for a single AST literal.

Native decoding deliberately calls the existing checked `Term::var`, `Term::iri`, `Term::sequence_marker`, `Term::app`, `Term::rdf_literal` and `Formula::atom` constructors. It therefore refuses empty/blank term identities, nullary applications, and invalid atom relation/contextual coordinates that derived Serde could previously restore without constructor checks. This is explicit native admission, not a claim that every raw derived-Serde enum value remains admissible. Encoding still faithfully carries the stored value; existing Serde admission remains unchanged except for factoring its unchanged single-literal component normalization into a shared implementation.

Compiler severity emits the mixed-case strings `Error`, `Warning` and `Info`, rather than the uppercase display tokens returned by `as_str`. Unit enum admission also accepts their exact singleton-null-object forms. Diagnostic fields stay ordered severity/code/message/subject; missing or null subject becomes None and emits explicit null. Records admit objects, ignore unknown fields and refuse known duplicates. Enum objects must contain exactly one member, including when duplicate keys repeat a tag. Member and array-index pointers locate native shape, field and constructor refusals. Positional struct payload arrays are not admitted.

The complete logic-module observation channel uses these codecs at its original cache, publisher and authenticated reader. BuildIdentity remains with its existing native owner; recorded reconstruction failures reuse the shared fixed-RecordedDiag reader/writer and retain complete causal nodes. Sets/maps keep their order and vector endpoints preserve multiplicity. Typed maps admit every duplicate value before keeping the last value; record fields and enum tags still refuse duplicates. Endpoints default values still require both source and target fields at decode. Source identities, compiler work, vocabulary extraction and corpus assertions are unchanged. Authored codec tests construct plain ASTs and diagnostic values; they do not parse canonical sources, reconstruct repository formulas, execute producers or load selected corpus artifacts.
