# Selection, waking appraisal and phase endings

DreamSelection and WakingAppraisal are InformationObject kinds: persistent
source records, distinct from selection or appraisal acts. Neither adds an
Experience subclass. InquiryCategory and PhaseCompletion are open QualityValue
vocabularies. The first has no seeded members; the second has one explicit
nonterminal disposition. No missing field produces a default or inferred act.

The two selection bridges are necessary because existing predicates have
different meanings. evokes records erotetic implication, while hasAboutness
records an AboutnessMode, so neither means the actual question selected for
self-inquiry. selectionQuestion names that Question. awarenessMode describes
actual experiencer state; selectedAwarenessMode records a choice in a record.
The choice does not imply the dream entered that mode (Principles 4 and 9).

The draw digest retains its own tagged lexical evidence, rather than
specializing contentDigest and thereby naming the selection artifact's bytes.
The canonical lexical law is a necessary source-consistency check, not a
cryptographic verifier, draw replay or randomness certificate. dreamSequence
binds only the actual experiencer and exact source-attributed number statement;
it is not a source stream identifier, list ordinal or global ordering. Tied
values, gaps and independently scoped restarts remain valid.

All supplied prose fields admit xsd:string, rdf:langString and rdf:dirLangString.
They retain untagged text when that is all the source supplies, and preserve
language and base direction without guessing. The wording of a Question itself
continues to use the existing language-bearing questionText contract;
questionContext is distinct surrounding source text. rawAppraisalText's
additional-content meaning requires the source's actual judgment. Lexical
difference cannot prove that text is more than serialization, and the ontology
does not pretend to execute such a proof.

The four waking-connection fields have a canonical union domain of
InformationObject and Analogy. An ordinary descriptor satisfies that domain
without becoming an Analogy. Analogy already mediates actual source and target domains and element
correspondences. Forcing that class from an unresolved candidate string would
fabricate those bindings. Plain descriptors therefore remain ordinary source
records; actual structured analogies retain all existing inference obligations.
A citation string never proves its cited evidence. Appraisal, answerhood,
accepted answer and solver-selected analogy remain different assertions.

Each of the four connection properties has a separate realized Constraint with
a binary subject guard and an InformationObject-or-Analogy type consequent.
These laws provide explicit subject admission at each property's SubjectsOf
target. The anonymous union domain remains the canonical inference axiom, but
the generic closed-world domain projection does not itself derive a subject
check from that anonymous union. The property-targeted laws supply that check
without a class guard that would hide malformed subjects, and without forcing
an InformationObject descriptor to become an Analogy.

The selection, sequence and phase laws use supported binary subject guards:
lotteryDigest, dreamSequence, phaseCompletion and preemptedAfter. The phase
laws require actual Event occurrences typed by EventType inside a dreaming
Experience; preemption must name a constituent of that same dream. They assert
no temporal total order, successful completion or runtime cancellation.
No alternate phase class or phase-text class is introduced.

Partial phase output is an InformationObject derived from the actual phase
Event. continuationReason is likewise on an InformationObject because its
description superproperty has Entity domain; putting it on the dream Event
would falsely mix endurant and occurrent categories. Waking override wording
remains source evidence rather than enactment. Native exact statements carry
writer and standpoint attribution independently (Principles 2, 4, 9, 17 and 19).

Direct dependencies follow the actual canonical carriers and predicates:
kernel, entities, events, awareness, inquiry, inference and standpoint extend the existing
mentation/provenance composition. Core inquiry owns questionContext and gains no
dependency on dreaming. The Analogy union branch directly consumes inference,
whose declared dependencies contain no return edge to dreaming.
